SQL Injection

CWE-89 · PaymentController.java:55
▶

Untrusted input is concatenated into a SQL query, letting attackers alter its structure. CargoCats' dataservice builds a payment query by string concatenation.

Quiz: What is the single best defense?

✅ Parameterized queries / prepared statements
❌ Escaping quotes manually
❌ Hiding SQL errors

Status: Completed
2

Weak Cryptography

CWE-327 · Digester.java
▶

MD5 is cryptographically broken and unfit for passwords or integrity. Two CargoCats services still call it.

Quiz: Best choice for password storage?

✅ bcrypt / Argon2 (adaptive, salted)
❌ MD5
❌ Plain SHA-256

Status: In progress
3

Cross-Site Scripting

CWE-79 · /api/shipments/track
▶

The trackingId parameter is reflected without encoding, letting attackers inject script into a victim's browser session.

Quiz: Primary defense for reflected XSS?

✅ Context-aware output encoding
❌ Client-side validation only
❌ Blocking the <script> word

Status: Not started
