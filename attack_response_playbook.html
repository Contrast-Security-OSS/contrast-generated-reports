No Active Incidents

ADR reports zero active attacks. This playbook stands ready for activation; the phases below define the response should that change.

NIST Response Phases

① Preparation

▶
  • Maintain the response plan and on-call rotation
  • Keep ADR, Assess, and logging tooling healthy
  • Run tabletop exercises quarterly

② Detection & Analysis

▶
  • Triage ADR alerts; classify exploited vs. probed
  • Determine attack vector and affected applications
  • Establish an incident timeline from logs

③ Containment

▶
  • Isolate affected services; preserve forensic evidence
  • Block source IPs at the perimeter / WAF
  • Apply ADR virtual patches where available

④ Eradication

▶
  • Remove malicious artifacts and persistence
  • Patch the root-cause vulnerability (see SmartFix)
  • Validate no re-entry paths remain

⑤ Recovery

▶
  • Restore services in phases with integrity monitoring
  • Confirm clean state before reopening traffic
  • Document lessons learned and update this playbook
