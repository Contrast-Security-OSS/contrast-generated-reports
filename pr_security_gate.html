⚙️ Security Gate Policy Rules
Critical Severity
BLOCK PR
Any new Critical severity vulnerability will immediately block the PR from merging. Requires immediate remediation before merge approval.
High Severity
BLOCK PR
New High severity vulnerabilities block PR merges. Must be fixed or explicitly approved by security team with documented justification.
Medium Severity
WARN
Medium severity findings generate warnings. Review required but won't block merge. Create follow-up tickets for remediation.
Low / Note
PASS
Low severity and informational findings are tracked but don't impact merge status. Address during regular maintenance cycles.
Additional Policies:
  • All vulnerabilities must be analyzed within code changes only (diff-based scanning)
  • Pre-existing vulnerabilities in unchanged code are tracked separately
  • Security team can override blocks with documented approval
  • Automatic re-scan triggered on each commit to PR branch
